# SOCKSY 🧦

**SOCKSY** — дизайнерские носки с характером.

Полноценный интерактивный лендинг для портфолио.

## Фишки

- Навигация по настроению (4 карточки: дерзкий, минималист, уютный, абсурдный)
- Каталог с 9 уникальными дизайнами
- Добавление в корзину с анимацией
- Детальная карточка товара ( размеры, состав, описание)
- Корзина с удалением и расчётом итого
- Форма доставки с картой (Leaflet + Nominatim reverse geocoding)
- Тосты, анимации, плавные переходы
- Полностью адаптивный дизайн (mobile-first)

## Технологии

- Vanilla HTML5 + CSS3 + JavaScript (ES6)
- Leaflet.js для интерактивной карты
- CSS переменные и ключевые кадры

## Как запустить

1. Клонируй репо
2. Открой `index.html` в браузере

Или открой на GitHub Pages (Settings → Pages → Deploy from branch `main`).
