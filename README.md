# 🧦 Socksy

Пример интерактивного магазина дизайнерских носков. 
Никаких серверов и баз данных — всё чисто на фронте (JS/HTML/CSS), корзина хранится в памяти, чтобы можно было поклацать и посмотреть, как это выглядит.

## Что тут есть
- Каталог товаров с модалками
- Добавление в корзину и подсчет суммы
- Оформление "фейкового" заказа
- Микроанимации и чистый UI
